# diffbeacon-consumer-smoke

Synthetic throwaway repository used once to test a real external consumer invocation of the
published DiffBeacon GitHub Action. Contains no real code, no real credentials and no real data.
Safe to delete.

## Synthetic surfaces present on the feature branch

- `src/auth/session.ts` — an authentication-shaped path with a changed predicate
- `src/runtime/handler.ts`, `src/runtime/pool.ts` — implementation files
- `package.json` — a dependency manifest change with no lockfile change
- no test file changes at all, which is itself part of what the smoke observes
